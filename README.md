```


Tracks burned AVAX fees per block on the Avalanche C-Chain using Web3.py and
the Avalanche API. Stores results in a local database and renders them in an
EJS dashboard via Express.

Built as a data exploration tool for on-chain fee analysis.

<br>

```
▓▒░ 0x01 // STACK ░▒▓
```


| layer | tech |
|---|---|
| chain | Avalanche C-Chain (EVM) |
| backend | Node.js · Express |
| templates | EJS |
| data | Web3.py · Avalanche API |

<br>

```
